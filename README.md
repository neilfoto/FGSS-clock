# 粉嶺官立中學 · 課室時鐘

課室投影用嘅時鐘網頁，以 16:9 電腦畫面為主。

## 使用方法
1. 雙擊 `index.html`，用 Chrome 或 Edge 開啟。校徽、字型同程式全部包喺呢個檔案入面，**唔使上網都用得**。
2. 撳右下角「全螢幕」掣、按鍵盤 **F**，或者雙擊畫面，就會全螢幕顯示。再做一次或者按 **Esc** 就會退出。
3. 滑鼠停咗 3 秒之後，游標同按鈕會自動隱藏；郁一下滑鼠就會再出現。

## 顯示內容
- 最頂置中：校徽同「粉嶺官立中學」。
- 中間：跟電腦本身嘅時間，用 24 小時制顯示「時：分」，冒號長亮唔閃。數字係純白色、粗身 sans serif 嘅 Inter Bold，每個數字闊度一樣，時間轉嘅時候唔會左右移位。
- 時鐘外面有一個幼身、金屬質感嘅復古外框。
- 時鐘下面：中文日期同星期，例如「2026年10月3日　星期六」，過咗午夜會自動轉。

## 小提示
- 時間同日期準唔準，視乎部電腦嘅系統時間。
- 瀏覽器支援嘅話，網頁開住期間會盡量防止螢幕自動休眠；如果仍然會休眠，就要喺 Windows 電源設定入面調整。

## 字型授權
- 時鐘數字：Inter Bold；日期數字：Inter Medium（SIL Open Font License 1.1）
- 校名及按鈕文字：Noto Sans CJK HK Bold（SIL Open Font License 1.1）
- 日期中文：Noto Sans CJK HK Regular（SIL Open Font License 1.1），已包齊 0–9、年、月、日、星期、一至六
以上字型都只保留咗用到嘅字，直接包入 `index.html`。
